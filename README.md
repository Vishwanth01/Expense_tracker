# 🚖 Fare Calculator – Travel Optimizer

A simple Python console application that calculates travel fares based on the selected vehicle type, distance traveled, and travel time. The program also applies surge pricing during peak hours to simulate real-world ride-hailing services.

---

## 📌 Project Overview

The Fare Calculator – Travel Optimizer helps users estimate travel costs by selecting a vehicle type and entering the distance traveled and journey start time. The application calculates the fare using predefined rates and applies surge pricing during peak hours.

This project demonstrates the use of Python dictionaries, functions, conditional statements, and user input handling.

---

## ✨ Features

✅ Supports multiple vehicle types (Economy, Premium, SUV)

✅ Calculates fare based on distance traveled

✅ Applies surge pricing during peak hours (17:00–20:00)

✅ User-friendly console interface

✅ Beginner-friendly Python implementation

---

## 🚗 Vehicle Rates

| Vehicle Type | Rate per KM |

---

## ⚙️ How It Works

1. User selects a vehicle type.
2. User enters the start hour of the trip.
3. User enters the distance traveled in kilometers.
4. The program calculates the base fare.
5. If the trip starts between 5 PM and 8 PM, surge pricing is applied.
6. The final fare is displayed.
